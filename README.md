# FIR Band-Pass and Band-Stop Filters

## 📌 Description

This project demonstrates the design of **FIR Band-Pass and Band-Stop filters** using the **Windowing Technique** in MATLAB.

A **Hamming window** is used for filter design.

## ⚙️ Specifications

* Sampling Frequency: **1000 Hz**
* Cutoff Frequencies: **100 Hz – 300 Hz**
* Filter Order: **50**
* Window: **Hamming**

## 📁 Files

* `Band_Pass_Filter.m` – Design of FIR Band-Pass filter.
* `Band_Pass_Filter.png` – Plot of FIR Band-Pass filter.
* `Band_Stop_Filter.m` – Design of FIR Band-Stop filter.
* `Band_Stop_Filter.png` – Plot of FIR Band-Stop filter.
  
## 🛠️ Software

**MATLAB**

## 📊 Result

The frequency response of both filters is plotted using `freqz()`.
